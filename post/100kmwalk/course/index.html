■ 行橋～別府100キロウォーク

  • 大会ＨＰ : https://yb100.jp
  • 主催 : 行橋～別府100キロウォーク実行委員会
  • 開催時期 : 10月中旬
  • スタート地点 : 福岡県行橋市 今川河川敷
  • ゴール地点 : 大分県別府市 別府的が浜公園
  • 距離 : 100.9 km
  • 制限時間 : 26 時間
  • コース難易度 : ★★★☆☆
  • コース詳細 (2025年) ( KMZ ファイル )

 

（解説）

参加者数が 4,000 人を超える、日本国内では最大の100kmウォーク大会である。加えて、初開催が1999年と 数ある100キロウォーク大会の中でも歴史のある大会でもあり、100km ウォーカーの間では特別視されている。開催を積み重ねることで地元にもしっかりと浸透しており、コース沿道での私設エイドもちらほらと見かけられる。

とにかく参加人数の多い大会なので、後方集団を歩いていると コンビニなど店舗で飲み物を補充しようとしても先行勢によって買い切られてしまうリスクがある。スタートから 15km は沿道に売店はないので、最初の 20km を歩くのに必要な飲み物は自前で用意しておきたい。10月開催とはいえ日中の気温が 25℃ を超えることも珍しくなので、直射日光から身体をガードする熱中症対策は必要不可欠である。また、行橋の大会はスタート時刻が 12:00 と遅く、それまでの間を日陰のない河川敷で過ごさなければならないので、晴天時にはスタートまでの待ち時間のあいだに体温を上げないことも必要になってくる。

4,000 人を超える参加者数にも関わらず 序盤は道幅の狭い道が続くので、後ろの方からスタートしてしまうと先にスタートした参加者を追い抜くのが大変になってしまう。無理をして道の端っこから追い抜こうとすると、舗装状況がよくなく足元が不安定なところを歩くことになるので 足を痛めるリスクがある。過去の行別の大会を 16時間以内 ／ 18時間以内 ／ 20時間以内（白ゼッケン）で完歩した経験のある方は そのグループ順に前方からスタートできる権利がもらえるので、タイムアタックをする場合には迷わず権利を行使したい。行別に初参加（青ゼッケン）であっても、他大会で同様の完歩タイム実績があることを申告すれば青ゼッケンが赤帯付きのものになり、同じ権利が与えられる。

コースは 60km 過ぎの CP2 宇佐までは比較的平坦な道が続くが、そこから国東半島の根本を３つの峠を越えて横断していく かなりトリッキーなコースだ。３つの峠のうち、１つ目の立石峠 (標高 147m) は登り傾斜は緩やかで 坂道を歩き慣れているウォーカーなら苦労はしないだろう。２つ目の七曲り峠 (標高 175m) は、国道10号沿いにある七曲り峠の入口から峠のピークまで 約 750m のあいだに高低差 112m を登ることになるので、大会屈指の難所として広く知られている。その七曲り峠のせいで認知度が低いものの、３つ目の赤松峠 (標高 132m) も七曲り峠に劣らぬ難所だ。

３つの峠を超えた先にある CP3 日出からは、再び平坦なコースがゴールまで続く。したがって、これら３つの峠をどのように攻略するかが鍵になるだろう。全体的なコースの難易度としては少し難しい部類に入る。

実際に大会コースを歩いた感想としては、行別は経験値が要求されるコースだ。タイムを追及するという観点から見れば、事前にコースを何度も試し歩きできる地元勢が圧倒的に有利なコースである。過去大会のリザルトを見ると、毎回のように福岡県・大分県勢が上位をほぼ独占しているのがその証拠である。遠征組がこのコースでサブ15を狙うのは極めて難しい。

前述したように行別はトリッキーなコースなので、力押しだけで攻略するのは難しい。余力計算をしながら峠を乗り越えていく立ち回りが要求される。

  • CP2 に着いて峠越えを迎える前に、どれだけ足を残せているか
  • 峠を越えて CP3 に着いた時点で、どれだけ足を残せているか

この２点が重要になるだろう。CP3 からゴールまでは平坦な道が続くが、足を使い切ってしまうと大失速してしまうので留意されたい。足の状態に不安のある場合は 峠をゆっくり登り下りした方が足を温存できるので、そうした方が最終的なタイムも期待できるだろう。

行別のコースはいかに３つの峠を乗り切るかが重要なので、タイムを追及する方でなくても、坂道を登り下りするウォーキングの練習は十分にやっておいた方がよい。関西では国道308号線の暗峠大阪側区間が七曲り峠と同等の傾斜があるので、事前のシミュレーション舞台として活用できる。大会では七曲り峠の入口で杖を配布しているが、杖自体に重さがあるので 杖なしで登れるならば杖無しで登った方がよい。

私見ではあるが、行別は特別な大会なので、初回はタイムを追及せずに まずは行別という大会を楽しむことを第一にするのがよいのではないかと思う。

 

■ 晴れの国おかやま24時間・100キロ歩行

  • 大会ＨＰ : https://okayama24h100k.main.jp
  • 主催 : 晴れの国おかやま24時間・100キロ歩行実行委員会
  • 開催時期 : 5月上旬（例年 5/3 ～ 5/4 に開催）
  • スタート地点 : 岡山市 後楽園河川敷
  • ゴール地点 : 岡山市 後楽園河川敷
  • 距離 : 100.1 km
  • 制限時間 : 24 時間
  • コース難易度 : ★★☆☆☆
  • コース詳細 (2026年) ( KMZ ファイル )

 

（解説）

晴れの国・岡山を巡る100kmウォークの大会。参加人数は全部門合わせて 1,000人を上回る規模で、100kmウォークの大会としては大きな部類に入る。２名１組で 43kmのコースを歩く親子の部、３人１組で 100kmのコースを歩くチームの部があるのが特徴である。

岡山県下の企業が多数協賛している地元密着型の100kmウォーク大会で、コース前半は私設エイドが大会運営を補ってくれているのが嬉しい。コース後半は沿道にコンビニが点在しているので、補給に困ることはないだろう。

コースは、序盤は干拓地が広がるエリアを進んでいくので 40km 付近までは平坦な道が続く。コース全体で見ると、大きなアップダウンは 42km 地点にある伊坂峠 (標高 159m)、60km 地点の閑谷緑地公園から和気方面へ抜ける広域農道 (最大標高 211m)、82km 地点の桜が丘 (最大標高 84m) の３箇所ある。実際に歩いて見て 傾斜がきつく登りにくいと感じたのは伊坂峠で、あとの２つは登りにくさを感じることはなかった。むしろ、閑谷緑地公園の 5km 手前から続くダラダラとした登り坂の方が精神的にもキツさを感じるだろう。

全体を通して信号の密度が低いので、100km ウォーク大会の中でもタイムを狙いやすいコースである。序盤は道幅のあまりない河川敷のコースを進むため渋滞しやすいので、タイムを狙いたい人はなるべくスタートゲートに近い場所で待機するようにしたい。

制限時間は他大会よりも短めの 24時間に設定されている。最後尾には、制限時間ギリギリでゴールするペースで歩く赤鬼ペースメーカーが配置される。終盤は各ポイントで休憩しながら進んでいくので、もし赤鬼たちに遅れをとることがあっても追いつくチャンスは残されているから 制限時間内での完歩を目指す人は頑張ってほしい。

注意点として、岡山は晴れの国と呼ばれるだけあって大会は天候に恵まれることが多いものの、雨が降った場合は一転して難易度が上がる。特にコース後半の 閑谷 ～ 和気 ～ 桜が丘 の区間は山間部を通るため、雨が降ると夜間の冷え込みと相まって体感気温が 10℃近くまで下がるので要注意である。５月にも関わらず CP2 の 磐梨中学校でストーブが大活躍するくらいのなので、雨天が予想される場合には雨対策だけでなく防寒対策も万全にしておきたい。

■ 東京エクストリームウォーク100

  • 大会ＨＰ : https://www.asahi.com/xtremewalk/tokyo/
  • 主催 : 株式会社朝日新聞社
  • 開催時期 : 5月下旬
  • スタート地点 : 神奈川県小田原市 小田原城址公園
  • ゴール地点 : 東京都江東区 livedoor URBAN SPORTS PARK (有明アーバンスポーツパーク) ※ 開催年によって異なる
  • 距離 : 100 km (公称)
  • 制限時間 : チャレンジクラス 26 時間 ／ エキスパートクラス・リレー部門 24 時間
  • コース難易度 : ★☆☆☆☆
  • コース詳細 (2026年) ( KMZ ファイル )

 

（解説）

参加者数が 2,000 人超の規模を誇る、東日本では最大級の100kmウォークの大会である。当初エクストリームウォークは関東と関西で100kmウォーク大会を開催してきたが、2026年から 50kmをメインとした大会形式に改められ、100km部門は年１回のフラッグシップ大会として行われるようになった。６つの区間を複数人でバトンをつなぐリレー部門もある。

運営スタッフがボランティア頼みである他の100kmウォーク大会とは異なり、エクストリームウォークは大会運営をイベント運営企業に委託しているらしく、各 CP やコースに配置されているスタッフの数は他大会と比べて桁違いに多い。ゴール会場には DJ までもが配置される力の入れようである。それだけに人件費が馬鹿になっておらず、それがエクストリームウォークの参加費の高さに繋がっている。もっとも、参加者やスタッフの数が多いことから個人で初めてウォーキング大会に参加する敷居が低く、エクストリームウォーク50K 共々初めてのウルトラウォーク大会としてはお勧めである。

エクストリームウォーク100は参加人数の多さだけでなく他の大会にはない華やかさがあり、その雰囲気は しばしば「100kmウォークのお祭り」と形容される。個人情報保護の観点からか、ゼッケンには氏名ではなくニックネームが記載されるようになり、各個人の大会リザルトも非公開である。タイムの計測方法も割とアバウトで、スタート前にスタッフがゼッケンのバーコードをスキャンした時刻がタイム計測の起点となるため、完歩証に記載されるタイムは実際に完歩に要した時間よりも長くなる。そういったところが、エクストリームウォークに対して好みが別れるところにもなっているようだ。

コースは小田原城址公園～東京都内を基調としており、ゴール会場は開催の都度選定しているようだが ここ最近は livedoor URBAN SPORTS PARK で固定されている。当初 CP1 は平塚市のしおかぜ広場に設定されており CP への出入りで砂浜を歩かされる鬼畜仕様だったが、車椅子での参加希望者に対応するようになったことからそうした障害要素は取り除かれ、茅ヶ崎海岸を通るルートも並行する国道134号との選択ができるようになり、年々コースの難易度は下がる傾向にある。

コースの難易度は易しい部類になるが、CP2 を出て 6km 先にある遊行寺坂から CP3 にかけてアップダウンの大きな道が続いており、ここをどう乗り切るかが大事になってくる。特に、CP3 横浜市児童遊園地の手前 2km から続く登り坂は意外と手強く、戸塚駅 ～ CP3 のあいだで無理をすると後半に響いてしまうので留意されたい。横浜市児童遊園地に入ってから CP のある場所に続く道もかなり急な登り坂なので なかなか厄介である。CP3 のラスト 2km と公園内の登り坂は、息が切れないペースでゆっくり登っていくのが攻略のコツである。CP3 でチェックを受けるときに息が上がっていると、息を整えるのに時間がかかってしまい CP での滞在時間が伸びてしまうので リズムを崩す原因になりかねない。

先述した通り CP1 ～ CP2 の区間は茅ヶ崎海岸と通るルートと国道134号を通るルートのどちらかを選択できるが、海岸沿いの道の方が平坦で信号もないので時間短縮しやすい。しかし、海岸沿いの道は海風で飛ばされる砂の影響を受けやすく、大会前の１週間のあいだに道が砂に埋もれてしまう……ということも起きたりするのが実に悩ましい。シューズの中に砂が入ってしまうと難儀なので、シューズ用のショートスパッツ（ゲーター）を用意しておくと万全である。

主に都会を歩くコースなので、コースの途中にはコンビニも多く飲み物の補給には苦労しないだろう。ただし、大磯から CP1 を経て CP2 に至る区間にはコンビニが１店舗しかない（ファミリーマート 平塚虹ヶ浜店）ことだけは覚えておきたい。そのため、CP1 で貰える飲み物が水（500ml のペットボトル）なのかジュース（200ml の紙パック）なのかは事前に必ず確認しておくこと。

東京エクストリーム100のコース自体は難易度が低いものの、コース後半の横浜市内、京浜第一国道、東京タワー周辺に信号地獄が待ち構えており、サブ18以上を目指すウォーカーにとっては難関となる。それゆえに 100m ウォーカーからはタイムアタックの舞台として選ばれにくいようだが、このコースでサブ16、サブ15を達成する難易度は行橋別府にも劣らないといっても過言ではないだろう。なお、トップゴールの完歩タイムは近年だと15時間半前後となっている模様である。

東京・関西のエクストリームウォーク100を通算10回完歩すると、次回からゼッケンがレジェンド仕様のゴールドゼッケンになる。10回完歩するのは大変だが、目標にしている人は頑張ろう。
